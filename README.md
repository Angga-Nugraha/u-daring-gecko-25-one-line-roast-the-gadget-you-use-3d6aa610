## The roast

> One of my wireless earbuds always dies first, so I spend half my life listening in mono like it's 1962.

## How it works

`main.py` (Python standard library only) writes the single roast line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). The gate requires UTF-8 text of 1–200 characters; this line is 103 characters.

```sh
python3 main.py
```
